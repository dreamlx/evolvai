# ADR-008: Token 预算控制层愿景

## 状态
草案 (Draft) - 待进一步验证

## 背景

在讨论 EvolvAI 与 Serena 的定位关系时（见 ADR-007），我们发现一个更有野心的长期愿景：

**核心洞察**：与其定位为"AI 工具使用策略引擎"，不如定位为"Token 预算控制层"。

类比财务预算系统：
- 我们不能完全控制 LLM 的行为
- 但可以提供成本控制框架
- 让项目估算越来越准确

## 决策

### 长期愿景：Token 预算控制层

**价值主张**：让 AI 编程成本可预测、可控制、可优化

**架构定位**：

```
┌─────────────────────────────────────┐
│  EvolvAI (预算控制层)                │
│  • 预算设定和分配                    │
│  • 实时成本监控                      │
│  • 估算学习引擎                      │
│  • 成本分析报告                      │
├─────────────────────────────────────┤
│  MCP 工具封装层                      │
│  • Serena (代码分析)                 │
│  • Memories MCP (知识存储)           │
│  • 其他 MCP 工具...                  │
├─────────────────────────────────────┤
│  LLM 调用层                          │
│  • Claude / GPT / 本地模型           │
└─────────────────────────────────────┘
```

### 当前阶段：更聪明地使用工具

在验证长期愿景之前，先从"更聪明地使用工具"入手：

1. **软引导 + 硬约束**结合
2. **EvolvAI 智能循环**实现
3. **TPST 数据积累**为预估模型奠基

### 软约束 vs 硬约束的定位

| 类型 | 目的 | 机制 |
|-----|-----|-----|
| 软约束 | 提高决策质量 | think_about_* 引导 AI 反思 |
| 硬约束 | 控制决策后果 | ExecutionPlan 设置边界 |

**关键区别**：
- 软约束：让 AI 想清楚再做
- 硬约束：即使想清楚了也有边界

**硬约束的核心价值不是"安全防护"，而是"资源效率控制"**：
- ❌ 不是防止 AI 犯错（git 可以回滚）
- ✅ 是防止 token 浪费（无法回滚的成本）

## 财务预算类比

| 财务预算 | EvolvAI Token 预算 |
|---------|-------------------|
| 年度预算 | 项目 token 预算 |
| 部门预算 | 任务 token 预算 |
| 实际支出 | 实际 token 消耗 |
| 预算偏差分析 | TPST 分析 |
| 成本中心 | 工具/操作类型 |
| 预算修正 | 估算校准学习 |

## 演进路径

### Phase 1: 更聪明地使用工具（当前）

- EvolvAI 智能循环
- think_about_* 软引导
- ExecutionPlan 硬约束
- 基础 TPST 数据收集

### Phase 2: 成本可见性

- 预算设定 API
- 实时消耗追踪
- 历史报告生成
- 简单预估模型

### Phase 3: 成本可控性

- 预警和中断机制
- 跨项目数据聚合
- 复杂任务预估
- 团队预算管理

### Phase 4: 成本可优化

- 估算学习引擎
- 行业基准对比
- 自动优化建议
- 企业级功能

## 风险评估

| 风险 | 等级 | 缓解策略 |
|-----|-----|---------|
| 预估准确性 | 高 | 从简单场景开始，积累数据 |
| 用户接受度 | 中 | 先服务成本敏感用户 |
| 技术复杂度 | 中 | MVP 优先，迭代演进 |

## 与现有能力的关系

| 现有能力 | 在新框架中的角色 |
|---------|-----------------|
| ExecutionPlan | 单次操作的预算限制 |
| TPST 分析 | 成本效率评估指标 |
| Area Detection | 减少搜索成本的策略 |
| Propose/Apply | 预览成本后再执行 |

**所有现有能力都纳入新框架，无需重构。**
